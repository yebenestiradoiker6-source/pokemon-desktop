# Pokémon assets

Coloca aquí cada Pokémon con este formato:

```text
assets/pokemon/
└── pikachu/
    ├── idle/
    │   ├── 001.png
    │   ├── 002.png
    │   └── 003.png
    └── walk/
        ├── 001.png
        ├── 002.png
        ├── 003.png
        └── 004.png
```

Si no existen PNG, la app generará un sprite temporal automáticamente para que puedas arrancar sin romper el proyecto.
